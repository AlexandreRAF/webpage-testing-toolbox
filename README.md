# Webpage Testing Toolbox
**An open-source toolkit for assessing and testing webpages under real-world conditions.**

### Setup/First Run

First, create the Python virtual environment with:
- ```venv_creation_components/create_venv_linux.sh``` - on Linux.
- ```venv_creation_components/create_venv_windows.bat``` - on Windows.


Then the program with:
- ```./run_linux.sh``` - on Linux.
- ```./run_windows.bat``` - on Windows.
